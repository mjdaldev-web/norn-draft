Settings

Norn Draft

Choose local defaults for drafting replies later.

AI provider

Choose which provider Norn Draft uses when generating replies.

API key

Stored locally in this browser for the selected provider. It is not validated here.

Gemini model

Applies when Gemini is selected as the AI provider.

Recommended uses Gemini 3.5 Flash. Flash-Lite is faster/lighter. Pro models may require special API access. If your API project has access to a Pro model, use Custom model name.

OpenAI model

Applies when OpenAI is selected as the AI provider.

Recommended uses the default OpenAI model selected for Norn Draft. Mini is more cost-friendly. GPT-5.5 may cost more or require access. Custom is for advanced users.

Draft defaults

Used by the popup when it opens.

Privacy and security

  • API key is stored locally in this browser using chrome.storage.local.
  • Norn Draft V1.3 does not read the current page.
  • Only popup text, selected tones, mode, and optional context are sent to the chosen provider when generating.
