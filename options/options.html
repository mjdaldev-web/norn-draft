Local reply history

Optional and off by default. Saved replies stay in this browser only.

History detail level

Detailed history saves your original message/draft and optional context locally in this browser. This may include sensitive details such as names, dates, case numbers, or customer information. Enable only if you are comfortable storing this locally. API keys are never saved in history.

Basic history saves generated replies and basic metadata only. Detailed history also saves the message/draft and optional context you typed.

Privacy and security

  • Gemini and OpenAI API keys are stored separately and locally in this browser using chrome.storage.local.
  • API keys are never saved in reply history and are never sent to the other provider.
  • Norn Draft only processes content when you explicitly request a draft or rewrite.
  • When you generate, the requested content and selected settings are sent to the chosen AI provider's API.
  • Local reply history is off by default and stored locally only when enabled.
  • Basic history saves generated replies and metadata only.
  • Detailed history also saves the original message/draft and optional context locally if you explicitly select it.
  • API keys, raw API responses, page URLs, page titles, clipboard data, and browser page content are never saved in history.
