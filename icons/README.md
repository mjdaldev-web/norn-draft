# Icons

Extension icons are generated from `norn-draft-updated.png`.

Required sizes:

- 16x16
- 32x32
- 48x48
- 128x128

An extra `icon256.png` is also kept for release and portfolio use.

The master source is retained unchanged. Runtime icons are `icon16.png`, `icon32.png`, `icon48.png`, and `icon128.png`.
