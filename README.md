# Norn Draft

Initial scaffold for the Norn Draft browser extension.

## What is included

- Manifest V3 extension setup
- Popup UI
- Options/settings page
- Documentation folder
- Icon placeholder folder

## Load unpacked

1. Open Chrome or Edge.
2. Go to the extensions page.
3. Enable Developer mode.
4. Choose **Load unpacked**.
5. Select this project folder.

## Project structure

- `manifest.json`
- `popup/`
- `options/`
- `docs/`
- `icons/`

## Notes

- API integration is intentionally not included yet.
- Icons are not wired up until actual image assets are added.
